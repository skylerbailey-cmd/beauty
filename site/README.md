# sky-sale.com

The marketing site. Plain HTML, no build step — open `index.html` to work on it.

Published to GitHub Pages by `.github/workflows/site.yml`, which runs only when
something in this folder changes. `CNAME` holds the custom domain; deleting it
would move the site back to the github.io address.

Screenshots in `assets/` are the real interface photographed against a seeded
demo store — "Marigold Skin Studio", with invented staff, customers and sales.
No figure or name in them belongs to a real customer. Regenerate them rather
than editing them by hand, and never replace them with captures of live data.
