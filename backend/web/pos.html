Maverick Payments Connection

Connect this company's Maverick account to reconcile batches against recorded sales (Transactions → Run Batch Audit). The token is stored securely on the server and never shown again.

Sale Text Alerts

Get a text whenever a sale is completed. Sent through your carrier's email-to-text gateway using this company's Gmail connection, so there's nothing to pay for — but delivery is up to the carrier and can occasionally be slow or dropped.

Pay Schedule

When payday falls and which period it settles. Changing this re-dates every paycheck in Reports → Payroll.

Payarc Connection

Connect this company's Payarc account. In the Payarc dashboard go to API, click the eye icon on your token's row, and copy the API Bearer Token from the pop-up — not the ID shown in the table, which won't authenticate. Stored on the server and never shown again.
